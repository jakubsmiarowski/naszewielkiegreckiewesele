DEMO ENVIRONMENT

How to test the demo

This environment is public and periodically reset. No production guest data is used.

1) Guest login (PIN)

Use one of the following PIN codes on the landing page:

111111 222222 333333

Each PIN opens a different scenario: complete RSVP, pending RSVP, and Car Pool mediation.

2) Demo admin login

Admin panel access is available through the "Sign in with Google" button on the landing page.

Demo admin account must be added in the demo Convex environment.

3) Quick test checklist

  1. RSVP: update answer and save.
  2. Car Pool: create an offer or send a ride request.
  3. Q&A: add a new question as a guest.
  4. Admin: open Admin tab and review alerts and questions.
  5. Reset: in Admin → Invitations click Reset demo data.

4) Reset schedule

Data can be reset manually (admin-only) and automatically using a scheduled reset script.

Recommended schedule: daily at 00:00 local time (Europe/Warsaw).
