# Feature Playbook

Goal: deliver a new capability with clear acceptance criteria.

Execution contract:

1. Confirm scope and non-goals.
2. Propose a brief implementation plan before edits.
3. Implement in coherent units (not scattered micro-edits).
4. Cover critical paths with tests.
5. Verify and summarize tradeoffs.

Output format:

- Scope covered
- Files changed
- Test coverage added/updated
- Verification run (`npm run check`, `npm run test`)
- Follow-up recommendations
